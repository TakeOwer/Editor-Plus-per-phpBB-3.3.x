# Editor Plus for phpBB 3.3

![Version](https://img.shields.io/badge/version-1.0.42-blue) ![phpBB](https://img.shields.io/badge/phpBB-3.3.x-teal) ![PHP](https://img.shields.io/badge/PHP-7.4%2B-purple) ![License](https://img.shields.io/badge/license-GPL--2.0-green)

**Editor Plus** (`salvocortesiano/editorplus`) enhances phpBB's posting toolbar: category menus, image dropdowns, smileys, icons, emojis, color picker with gradients, live preview, format-as-you-type, visual editor, server-saved drafts, syntax highlighting, mathematical and chemical formulas, scientific calculator, and a dedicated **Check-up** tab that automatically verifies proper functionality.

It works **with** Advanced BBCode Box (ABBC3) or **without** it: if ABBC3 is disabled or missing, it falls back to the standard phpBB toolbar using the same categorical menus.
Developed by **Salvo Cortesiano** for *Le Ombre della Rete 360°* (netshadows.de/ombra).

## 2. Installation, Updating, and Uninstallation

### First Installation

1. Copy the folder `salvocortesiano/editorplus` into your forum's `ext/` directory, resulting in `ext/salvocortesiano/editorplus/`.
2. ACP → **Customise** → **Manage extensions** → *Editor Plus* → **Enable**.
3. ACP → **General** → **Purge the cache**. This allows phpBB to register the `[syntax]`, `[math]`, and `[imath]` BBCodes.
4. Open ACP → **Extensions** → **Editor Plus** → **Check-up** and execute the **live tests**.

### Image Dropdowns Package

The `editorplus_pacchetto_ombre.zip` package contains a `data/` folder with preset forum dropdowns (`combos_ombre.json`). Place it inside `ext/salvocortesiano/editorplus/`, or import the JSON file directly via the **Dropdowns** tab.

### Updating to a New Version

1. Set the forum **offline** (ACP → Board settings → Disable board).
2. **Disable** Editor Plus. Do not select "Delete data", or settings, custom dropdowns, and drafts will be lost.
3. Replace the `ext/salvocortesiano/editorplus` directory and restore the `data/` folder if applicable.
4. **Re-enable** Editor Plus: phpBB will run database migrations automatically.
5. **Purge the cache** from the ACP.
6. Bring the forum back online, then run the **Check-up**.

> The Check-up tool alerts you if an update was incomplete (e.g., unreplaced files or cached legacy files in the browser).

### Uninstallation

- **Disable**: Turns off Editor Plus while retaining settings, dropdowns, and drafts.
- **Delete data**: Completely removes settings, draft tables, user preferences, KaTeX backups, test areas, and status files.

Previously posted messages remain readable without the extension: `[math]` and `[syntax]` blocks fall back to plain text.

## 3. The Posting Toolbar

Above the toolbar, an **info line** appears (can be disabled via ACP). For example: *Editor Plus 1.0.34 · Editor: BBCode (ABBC3 bar) · developed by Salvo Cortesiano*. It displays current version, mode (BBCode or Visual), and active toolbar.

### With or Without ABBC3

| | With ABBC3 | Without ABBC3 (Standard phpBB Toolbar) |
|---|---|---|
| Custom BBCode Buttons | Located in **category menus** | Located in **category menus**, using Editor Plus or ABBC3 icons |
| **Fonts** Dropdown | Replaces ABBC3's menu | Positioned next to the font size menu (if `[font]` BBCode exists) |
| **Font Size** Dropdown | Handled by Editor Plus | Uses phpBB's menu with Editor Plus styling |
| Image Dropdowns, Tools, GHide | ✔ | ✔ |

### Categorized Menus

Custom BBCodes are grouped into **Text, Effects, Video & Audio, Hidden, Links & Downloads, Structures, Other**. Each item displays an icon, label, and description. Categories can be rearranged via ACP drag-and-drop. Uncategorized BBCodes default to **Other**.

### Image Dropdowns

Dropdown menus with search filtering and **item previews**, such as *e-Book Covers* or *Movie Posters*. Created and managed in the ACP **Dropdowns** tab. A dropdown menu only appears if its corresponding BBCode exists on the forum.

### Styling

All toolbar select menus adapt to Editor Plus styling, **including dropdowns added by third-party extensions**, even when dynamically loaded after page render. Toolbar items wrap automatically on small screens.

## 5. Text Color: Gradients and Classic Palette

Clicking the color button (dropper icon on phpBB or ABBC3) opens the **Text Color** panel containing two tabs. Output always resolves to native phpBB `[color=#rrggbb]…[/color]` tags, ensuring universal readability without requiring custom BBCodes.

### Gradients Tab

1. **Base Palette:** 14 core shades (Red, Orange, Yellow, Green, Cyan, Blue, Purple, Pink, Brown, Grey, etc.).
2. **Shade Matrix:** Displays **11 tonal variations** of the selected base color, ranging from light to dark.
3. **Fine Tuning Controls:**
   - **Color Square:** Horizontal axis adjusts saturation; vertical axis adjusts brightness. Supports click-and-drag or keyboard arrow navigation (`Shift` increases step size);
   - **Hue Slider:** Rotates color spectrum while maintaining current saturation and brightness;
   - **Hex Code Input:** Direct input (`#1e88e5`, leading `#` optional). Press `Enter` to submit;
   - **Eyedropper Tool:** Screen color picker support for compatible browsers (Chrome, Edge).
4. **Preview:** Displays selected text with chosen styling over forum background colors.
5. **Contrast Warning:** Alerts user if contrast ratio falls below 3:1 against post background, recommending lighter or darker tones.
6. **Recent History:** Stores last 12 used colors.
7. **Apply Color**: Wraps selected text in chosen color tags.

Opening the panel on existing `[color=…]` tags automatically pre-selects the tag's hex value.

### Classic Tab

Provides access to phpBB's traditional **125-color palette**. The panel persists the user's active tab selection.

### ACP Configuration

- **Gradient Color Picker**: Toggling off reverts the toolbar color button to default phpBB behavior.
- **Classic Palette Tab**: Show or hide the classic palette sub-tab.

Fully supported within **Visual Editor**, **Format-as-you-type**, and **ABBC3-disabled** modes.

## 6. Writing Assistance & Automations

- **Format-as-you-Type:** Renders formatted styling (bold, italic, color) directly inside the textarea while dimming active syntax tags. Optional color highlighting for `[size]` and `[font]` tags.
- **Drag & Drop / Paste Images:** Dragging or pasting image files automatically uploads them as **attachments** and inserts them into text.
- **Live Preview Attachments:** Renders `[attachment=N]` tags as **interactive thumbnail cards** complete with filename, file size, and comments. Clicking expands the image.
  - **Sequential Photos:** Automatically formats consecutive images into a gallery grid.
  - **Non-Image Files** (PDF, ZIP, Audio, Video): Renders with file type icons.
  - **Deleted Attachments:** Displays "Attachment not found" placeholders.
  - **Thumbnails:** Prefers pre-generated phpBB thumbnails; falls back to scaled previews without altering download metrics.
- **Rich Text Pasting:** Pasting from Word, Google Docs, or webpages strips extraneous formatting, invisible tags, pseudo-lists, and proprietary Word artifacts. Converts headings to bold text, converts tables to text rows, and purges all scripts, inline event handlers, `javascript:` protocols, and `iframe` elements.
- **Auto-Expanding Textarea:** Dynamically resizes input height during typing to avoid unnecessary scrollbars.
- **Real-time Counter:** Displays active character and word counts.
- **Dynamic Syntax Parser:** Maintains history state (`Ctrl+Z`), previews, and draft syncing even when external phpBB routines alter textarea contents (e.g., attachment removals).

## 7. Visual Editor

Configurable via ACP and toggled individually per user in the **Options** menu. Replaces raw tags with rendered visual elements. Use the **Visual / BBCode** button to switch modes on the fly.

- **Custom BBCodes** (spoilers, hide tags, video embeds): Displayed as **interactive blocks** or rendered with **full post styling** (ACP setting). Clicking opens a parameter edit modal with real-time preview.
- **Code & Math Blocks:** `[syntax]`, `[math]`, and `[imath]` render as locked structural elements to prevent accidental syntax corruption.
- **Data Integrity Protection:** Mode switching runs lossless validation. If structural markup drift is detected, mode conversion aborts to preserve original content.

## 8. Syntax Highlighting `[syntax]`

```
[syntax=php]
<?php echo "Hello World"; ?>
[/syntax]
```

- **Supported Languages:** PHP, JavaScript, HTML/XML, CSS, SQL, Python, Java, C/C++/C#, JSON, Bash, and more. Auto-detects language if omitted.
- **Post Display:** Features line numbering, language badge, one-click **Copy button**, and light/dark theme toggles (ACP controlled).
- **Literal Content:** Neutralizes BBCode and HTML execution inside code blocks.
- **Syntax Editor Modal:** Supports `Tab` indentation, tab-to-space conversion, and auto-formatting for HTML, CSS, JavaScript, and JSON.
- **Legacy Compatibility:** "Highlight [code] tags" option allows applying highlighting to standard phpBB `[code]` blocks.
- **Performance:** Highlighting scripts load conditionally only on pages containing highlighted code.

## 9. Mathematical and Chemical Formulas `[math]` `[imath]`

Formulas are authored in **LaTeX** syntax and rendered via **KaTeX**. Resources are fetched conditionally when math elements are detected on page.

| BBCode | Usage | Example |
|---|---|---|
| `[math]…[/math]` | **Display formula** (standalone, centered) | `[math]x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}[/math]` |
| `[imath]…[/imath]` | **Inline formula** (within text flow) | `area equals [imath]\pi r^2[/imath] square meters` |

### Math Modal (x² Button)

- **Categorized Symbol Palette:** *Basic, Fractions & Powers, Greek, Analysis, Sets & Logic, Matrices & Systems, Chemistry*. Clicking inserts symbols directly around active text selections (e.g., selecting `x` and clicking √ outputs `\sqrt{x}`).
- **14 Pre-built Templates:** Quadratic formula, Pythagorean theorem, Euler's identity, Mass-energy equivalence, Derivatives, Gaussian integral, Binomial theorem, Systems of equations, Determinants, Schrödinger equation, Photon energy, Methane combustion, Ammonia synthesis, Carbon-14 decay.
- **Live Preview Window:** Real-time LaTeX parsing with explicit syntax error diagnostics.
- **Placement Switch:** Toggle between "Display (centered)" and "Inline".
- **Formula Editing:** Selecting existing formula tags and opening the modal loads the equation for editing.
- **Reference:** Includes direct link to KaTeX official documentation.

### LaTeX Quick Reference

| Input | Output |
|---|---|
| `x^2`, `x_{i}` | Power, subscript |
| `\frac{a}{b}` | Fraction |
| `\sqrt{x}`, `\sqrt[3]{x}` | Square root, cube root |
| `\alpha \beta \pi \Omega` | Greek symbols |
| `\sum_{i=1}^{n}`, `\int_a^b`, `\lim_{x\to 0}` | Summation, integral, limit |
| `\le \ge \neq \approx \infty` | ≤ ≥ ≠ ≈ ∞ |
| `\begin{pmatrix} a & b \\ c & d \end{pmatrix}` | Matrix |
| `\begin{cases} x+y=1 \\ x-y=0 \end{cases}` | System of equations |

### Chemistry Syntax `\ce{…}`

| Input | Meaning |
|---|---|
| `\ce{H2O}` | Chemical formula (auto-subscripts numbers) |
| `\ce{CH4 + 2O2 -> CO2 + 2H2O}` | Reaction equation |
| `\ce{N2 + 3H2 <=> 2NH3}` | Chemical equilibrium |
| `\ce{SO4^2-}` | Ionic species |
| `\ce{^{14}_{6}C}` | Isotope notation |
| `\ce{A ->[\Delta] B}` | Reaction conditions over arrow |

> **Security Note:** HTML injection, arbitrary image loading, and external URLs via LaTeX are strictly blocked (`\href`, `\url`, `\includegraphics` commands are disabled). If KaTeX rendering is disabled, content displays safely as raw LaTeX source text.

## 10. Scientific Calculator

Accessible via the 🖩 button or as a sub-tab within the Formula dialog. Evaluates expressions **in real time as you type**, with confirmation via **Enter** or `=`.

### Features & Capabilities

| Expression Type | Examples | Output |
|---|---|---|
| Arithmetic | `2+3*4` · `(2+3)*4` · `2^3^2` | 14 · 20 · 512 |
| European Decimal Notation | `12,5*3` | 37.5 |
| Implicit Multiplication | `2pi` · `3(4+1)` · `2√3` | 6.283… · 15 · 3.464… |
| Percentages | `80*15%` | 12 |
| Roots & Powers | `√16` · `cbrt(27)` · `root(32;5)` · `(-8)^(1/3)` | 4 · 3 · 2 · −2 |
| Logarithms | `ln(e^2)` · `log(1000)` · `log2(1024)` · `logb(81;3)` | 2 · 3 · 10 · 4 |
| Trigonometry (DEG/RAD) | `sin(30)` (degrees) · `sin(pi/2)` (radians) | 0.5 · 1 |
| Combinatorics | `5!` · `nCr(10;3)` · `nPr(5;2)` | 120 · 120 · 20 |
| **Complex Numbers** | `sqrt(-4)` · `(3+4i)/(1-2i)` · `e^(i*pi)` · `abs(3+4i)` | 2i · −1 + 2i · −1 · 5 |
| **Physical Constants** | `h*c/(500e-9)` (500 nm photon) · `me*c^2/eV` | 3.97·10⁻¹⁹ J · 510998.95 eV |
| Memory Recall | `Ans*2` | Evaluates previous result |

**Function Parameter Separator:** `;` (semicolon), e.g. `nCr(10;3)`, reserving the comma for European decimal formatting.

### Available Functions

`sqrt` `cbrt` `root(x;n)` `abs` `arg` `conj` `re` `im` `exp` `ln` `log` `log2` `logb(x;b)` `sin` `cos` `tan` `asin` `acos` `atan` `sinh` `cosh` `tanh` `floor` `ceil` `round` `mod(a;b)` `nCr(n;k)` `nPr(n;k)` alongside operators `!` `%` `^`.

### Physical & Mathematical Constants (CODATA Standards)

| Symbol | Name | Symbol | Name |
|---|---|---|---|
| `pi` | Pi (π) | `NA` | Avogadro constant |
| `e` | Euler's number | `kB` | Boltzmann constant |
| `phi` | Golden ratio | `R` | Universal gas constant |
| `c` | Speed of light | `F` | Faraday constant |
| `h` | Planck constant | `G` | Gravitational constant |
| `hbar` | Reduced Planck constant (ħ) | `g0` | Standard gravity |
| `qe` | Elementary charge | `a0` | Bohr radius |
| `me` | Electron mass | `eps0` | Vacuum permittivity |
| `mp` | Proton mass | `mu0` | Vacuum permeability |
| `mn` | Neutron mass | `sigma` | Stefan-Boltzmann constant |
| `u` | Atomic mass unit | `alpha` | Fine-structure constant |
| `eV` | Electronvolt | `Ry` | Rydberg constant |

### Additional Features

- **DEG / RAD:** Toggle angle modes; settings persist across sessions.
- **Memory Storage:** `MC`, `MR`, `M+`, `M−`.
- **History:** Stores last 20 evaluations for quick re-use.
- **Insertion Options:** Insert **raw result** (`42`), **full equation** (`7*6 = 42`), or **LaTeX formula** (`[math]7 \cdot 6 = 42[/math]`).
- **Error Handling:** Explicit notifications for division by zero, domain errors, unbalanced parentheses, or syntax errors.
- **Security:** Evaluated via a custom math parser without using native JavaScript `eval()`.

## 11. GHide

When the **ntvy95/hide** extension is installed, Editor Plus adds **GHide** capabilities to restrict text visibility to specified users. Located in the **Hidden** menu or as a standalone toolbar button (ACP configurable).

- **Reply Detection:** Automatically populates user targets: *Topic Author*, *Self*, or *Both*.
- **Group Exemptions:** Configure administrative/moderator groups in ACP to bypass hide restrictions.
- **Tag Parser:** Native parsing for `[ghide]` tags even if unlisted in default phpBB BBCode tables. Includes "Force Recognition" override option.

## 12. Automatic Drafts

Background autosave triggers during text input: the editor status bar indicates *"Draft saved at 10:27"*.

- **Registered Users:** Drafts sync to the **server database** and local browser storage. Returning to the topic page triggers a recovery banner: *"An unsaved draft exists… Restore / Delete"*, accessible **across different browsers, devices, or protocol domains** (`http`/`https`/`www`).
- **Attachment Preservation:** Drafts save uploaded **attachment associations** and comments. Restoring a draft restores attachments to phpBB's upload queue (*Attachments* tab) with functional "Inline" and "Delete" controls.
  - **Validation:** Verifies attachments remain valid, belong to the active user, and are not bound to published posts. Metadata is validated server-side.
  - **Auto-renumbering:** Adjusts inline `[attachment=N]` index markers dynamically if new attachments are added.
  - **Availability Warnings:** Notifies user if previously saved attachments were purged server-side.
  - **State Triggers:** Adding or deleting attachments triggers draft syncs independently of text modifications.
- **Guests:** Saved locally in browser storage only.
- **Status Transparency:** "Draft saved" confirms successful server receipt. Network or database failures trigger alternative notifications (*"Saved in this browser only"* or red *"Draft NOT saved"*).
- **Purge Policies:** Submitting a post or manually clicking **Delete** clears stored draft data. Expired drafts are automatically purged based on ACP retention settings (up to 30 days maximum per user).
- **Encoding:** Draft contents are transferred and stored using base64/URI encoding to ensure compatibility with strict web application firewalls (WAF) or legacy database charsets.

## 16. Updating KaTeX from the ACP

ACP → Check-up → **"KaTeX Management & Updates"**.

1. **Version Detection:** Checks remote registry for compatible updates within the active release branch or major version upgrades (requires confirmation).
2. **Download & Testing:** Real-time **percentage progress bar** tracks 6 sequential execution stages:
   - *Version verification*
   - *Download progress tracking*: real-time byte counter (e.g., "721 KB of 1.4 MB", 49%)
   - *SHA-512 checksum validation*
   - *Archive extraction*
   - *Staging build preparation*
   - *In-browser diagnostic suite*: equation parsing and font asset validation
3. **Activation:** Deployment button activates **only upon successful verification pass**.
4. **Rollback System:** Previous installations are preserved at `store/editorplus_katex_backup/` and can be restored in one click. Restoring toggles active and backup builds, allowing forward and backward switches.

**Technical Details**
- Interruptions or validation failures trigger **red status indicators**, halt execution, and preserve active KaTeX installations.
- All deployment and rollback events log to the phpBB **Admin Log**.
- Version-tagged URIs force client browsers to invalidate cached static assets upon deployment.

> **Note:** Overwriting extension files via archive extracts resets KaTeX to the bundled release version. Official Editor Plus updates ship with up-to-date KaTeX builds.

**Server Requirements:** Remote download support (`cURL` or `allow_url_fopen`), `zlib` module, write permissions for extension root and `store/` directories.

## 17. Security

- **ACP Access Controls:** Administrative operations restricted to authorized board managers using form token authentication (CSRF protection).
- **AJAX Endpoints:** Preview, preference, and draft controllers enforce session validation and strict user ownership boundaries.
- **Literal Syntax Parsing:** Neutralizes HTML/BBCode execution within code and math blocks. Equations cannot inject DOM nodes, arbitrary images, or external links.
- **Rich Text Sanitization:** Strips executable script tags, inline event attributes (`onload`, `onerror`), `javascript:` protocols, and `iframe` elements during paste operations. Image sources restricted to secure `http`/`https` schemes.
- **Calculator Sandbox:** Custom AST parser prevents arbitrary code execution (`eval` free). Restricts operations strictly to registered function maps and constant identifiers.
- **KaTeX Package Validation:**
  - Packages fetched exclusively from `registry.npmjs.org` with verified source origins;
  - Mandatory **SHA-512 integrity checks**;
  - **Strict extraction whitelist**: excludes `.php` files and prevents directory traversal paths (`..`);
  - Enforces archive extraction size caps;
  - Requires successful client-side test passes prior to production activation.
- **Data Sanitization:** Sanitizes malformed UTF-8 sequences in smileys and BBCode definitions to prevent script execution halts.

## 18. Troubleshooting

Start diagnosis via: **Check-up → Run Live Tests**. System warnings highlight required corrective steps. Use **"Copy Diagnostic Report"** when requesting support.

| Symptom | Probable Cause | Corrective Action |
|---|---|---|
| Toolbar unchanged after update | Stale browser or server cache | Press `Ctrl+F5` and purge phpBB cache via ACP. Check-up will highlight version asset mismatches |
| "File version consistency" displays red | Incomplete file upload | Re-upload complete extension folder from original archive, disable/re-enable extension, purge cache |
| "Database migrations" displays red | Incomplete schema migration | Disable extension (without purging data) and re-enable |
| `[math]` or `[syntax]` rendered as plain text | Unpurged board cache post-install | Purge cache via ACP |
| Math formulas render with missing characters | Missing KaTeX font files | Review Check-up font diagnostic warnings: restore KaTeX backup or re-upload font assets |
| Drafts report "Saved in this browser only" | Server rejected draft request | Run Check-up "Server Drafts" test to inspect raw HTTP response output |
| Posting test notes "Server forbids framing" | Server sending `X-Frame-Options` headers | Toolbar functionality remains unaffected. Check developer console (`F12`) for `[Editor Plus]` logs |
| Category menus missing | Feature toggled off or categories empty | ACP → Settings → Categories → "Reset Default Categories" |
| "Fonts" dropdown missing without ABBC3 | Missing `[font]` BBCode definition | Expected behavior: dropdown mounts dynamically only when `[font]` BBCode exists |
| GHide button not appearing | `[ghide]` tag unrecognized | ACP → GHide → "Force Recognition" (verify `ntvy95/hide` is active) |
